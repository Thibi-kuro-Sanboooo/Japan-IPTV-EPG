# Japan-IPTV-EPG

Japan向け IPTV EPG の公開データ用リポジトリです。

生成プログラム本体は `Japan-IPTV-EPG-Generator` で管理し、このリポジトリには検証を通過した XMLTV 生成物だけを置きます。

## 現在の段階

開発初期のため、完成版 `guides.xml` はまだ公開しません。

最初の自前取得系統として ABEMA を実装・検証中です。公開開始後は次のような構成を予定しています。

```text
abema.xml       # ABEMA単独の検証済みEPG
guides.xml      # 全取得元を統合した完成版（後日）
status.json     # 生成日時・局数・番組数・検証結果（予定）
```

## 方針

- karenda-jp の `tvg-id` 互換をできるだけ維持
- 番組情報は可能な限り自前取得
- 検証に失敗した生成物では正常版を上書きしない
- 生成処理と公開データを別リポジトリで管理
