# PROJECT_RULES.md — Japan-IPTV-EPG

## 固有ルール
244局の日本向けXMLTV配布リポジトリ。ここは生成済み検証済みファイルの公開先であり、生成プログラムはJapan-IPTV-EPG-Generatorで管理。XMLTVやtvg-idの互換性を守り、検証失敗時は配布物を差し替えない。生成XMLはアプリのVer付きZIPルール対象外。
